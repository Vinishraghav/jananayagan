Deployment Notes

  1. Upload the 6.33GB video to a public host like Google Drive, Dropbox, OneDrive, AWS S3, or a streaming service.
  2. Get a public direct URL for the file and paste it into the input field above.
  3. If the video does not play, confirm the URL points directly to the MP4 file and is publicly accessible.
  4. Deploy this repo using GitHub Pages from the main branch, serving from the root folder.

GitHub cannot host a 6.33GB file directly in a normal repository, so the video is served from an external host.
