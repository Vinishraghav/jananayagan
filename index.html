🛡️ Privacy Guidelines

How do I stay completely anonymous?

1. Use a VPN to hide your IP address

2. Enable Private Mode on this player

3. Use CORS Proxy to hide from video host

4. Host video on privacy-friendly service (not Google/Dropbox if concerned)

5. Share link only via encrypted channels

Can the video host track me?

Default: Yes - They see your IP when you access the video

With VPN: Your IP is hidden

With CORS Proxy: The proxy's IP is shown, not yours

Recommendation: Use both VPN + CORS Proxy for maximum privacy

Can GitHub track me?

No. GitHub Pages doesn't track individual visitors. All processing happens in your browser.

Your video URL is stored only in your device's URL bar - never sent to any server.

Can someone record my video?

The "Disable Right-Click" option prevents browser context menu, but:

⚠️ Reality: Screen recording tools can still record the video

For maximum protection: Use password protection + private links only

Consider watermarking your video before uploading

What data is collected?

✅ Not collected:

- Your IP address (unless you visit video host directly)

- Your viewing history (local browser only)

- Cookies or tracking scripts

- Personal information

- Viewing duration or patterns

💡 Best Practices for Maximum Privacy

  1. Use a VPN - Hide your real IP address from everyone
  2. Enable Private Mode - Turn off all tracking features
  3. Use Private Link - Share only generated encrypted links, not direct URLs
  4. Password Protect - Add password to video if extremely sensitive
  5. Enable CORS Proxy - Hide identity from video host
  6. Share Carefully - Only share link via encrypted channels (Signal, WhatsApp, etc.)
  7. Use Incognito Window - Browse in private/incognito mode
  8. Disable Browser Tracking - Use Firefox with privacy settings or Brave browser
  9. Don't Enable Auto-Share - Don't let browser auto-save your video links
  10. Monitor Access - If video host supports access logs, review them regularly
